1

先测一下通不通

在 CMS 的「JSON接口在线解析/测试」面板里，接口地址填上面那个，点 测试接口。看到 HTTP 200 和 code / msg / page 这些字段，就是通的。

2

保存成采集源

进 采集 → 自定义资源库（或 接口管理）→ 新增 → 资源库地址粘贴上面那串 → 接口类型选 JSON → 保存。

3

点采集

回到列表，点刚才那个采集源旁边的「采集」按钮，条目就进来了。

手滑复制不上？点下面这个也行

能打开并看到一大坨 JSON，说明接口是好的，CMS 那边也能用。

导进去的是什么 先看一眼

  • 每一「条」是 一个资源站（比如「新极品资源站」），不是影视作品。
  • 条目里带状态、响应时间、评分、资源数量，点标题能跳到那个站。
  • 适合拿来做「资源站导航」栏目。如果你要的是影视内容，看下面这段。

你真正要影视内容的话

清单里每个资源站自己的采集接口地址都在这。打开 Excel，把「API采集地址」那一列一条条填进 CMS 的「采集 → 添加采集资源」里，就能采到剧。

清单里还有状态和响应时间，先接响应快的。离线站别接。

CMS 提示「无数据」？

  • 先确认接口类型选的是 JSON 不是 XML（XML 的话地址换成 .../api.php/provide/vod/at/xml/）。
  • 确认地址末尾有斜杠。
  • 「JSON接口在线解析/测试」面板如果显示 HTTP 200 但字段是空的，说明地址填错了，重新复制一次。
